# Demo questions for the operator chat

Thirty questions a judge is likely to ask, run against the live run (a copy, `runs/live-qa`, 9 episodes) through the
chat server on port 8793 with the viewer on episode 9, hour 40, ship 11 (MAUNA HALE) selected. Model: Gemini Argon via
`loop.player.make_model`. Questions were sent four at a time, so the times include queueing at the model.

Criteria for PASS: answers the question, numbers come from tools, operator voice, two to four sentences, no run
statistics unless asked, no "I cannot", under 45 s.

**Result: 23/30 PASS in round 1, 30/30 PASS in the final round.**
Spend: round 1 $0.30, all rounds together about $1.30 of model cost (plus the background verification Q15 started).

## What changed between rounds

- `chat/tools.py`: make_plan takes the optimal plan the task pack stores (instant, exact) and caches any solve that
  reaches the optimum; the solver fallback uses 8 workers and 20 s (4 workers missed the optimum under load). A ship
  name the line reuses (two MAUNA HALE calls) resolves to the selected ship, else the most late call. coach_round
  defaults to the latest round. run_status adds the model cost per episode.
- `chat/agent.py`: `route()` maps the question to the tools that answer it and the hint goes into the message, so
  most turns are one or two tool calls; the system prompt says how to answer "how much does an episode cost", reused
  names, and "what would you do differently". Past 25 s a tool-free backup answer on the routed tools' results races
  the agent and the first one wins; past 40 s the answer is built in code from the overview digest. The dash cleanup
  no longer turns a spaced dash between two numbers ("hour 292, 49 hours late") into a range, the sentence cap does not split after "vs.", and a leaked Gemini
  "thought" marker is stripped.
- `tests/test_chat_routes.py`: six demo questions through FakeModel pin the routing, plus the reused-name pick, the
  dash cleanup, the backup race and the code-built answer.
